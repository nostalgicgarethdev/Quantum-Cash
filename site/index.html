$QCash

A tiny blockchain that mixes Bitcoin, Solana and post-quantum signatures. Run it on your own computer.

⚠ Experimental testnet. Not money. No token, no sale, no CA.

> what it is

Bitcoin part
Coins live in UTXOs. Blocks are sealed with SHA-256 proof-of-work. 50 QCASH reward, halves every 210,000 blocks.
Solana part
Time is cut into slots. A Proof-of-History hash chain (12,500 SHA-256 steps per slot) proves the order of every transaction.
Quantum-safe part
Every spend is signed with W-OTS, a hash-only signature. No elliptic curves for a quantum computer to break.

> watch proof-of-history tick (in your browser)

This runs real sequential SHA-256 right here. Each line is one slot = 12,500 hashes.

> run a node in 4 steps

git clone https://github.com/nostalgicgarethdev/Quantum-Cash
cd Quantum-Cash && go build -o qcash ./cmd/qcash
./qcash wallet new -w me.json
./qcash node -miner $(./qcash wallet address -w me.json)

Then send coins: ./qcash wallet send <address> 12.5 -w me.json
